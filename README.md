## Featured Projects

### 1. Airline Fare Statistical Analysis

**Project Type:** Statistical Data Analysis  
**Tool:** Microsoft Excel  
**Role:** Data Analyst

Analyzed airline fare datasets for travel between Miami and Dallas/Fort Worth using Microsoft Excel.

The project involved organizing fare observations, calculating descriptive statistics, constructing a 95% confidence interval, and performing a two-sample t-test to evaluate whether average fares differed between the two travel directions.

#### Key Work Completed

- Organized and analyzed datasets containing hundreds of airline fare observations
- Calculated sample means and standard deviations
- Calculated standard errors
- Constructed a 95% confidence interval
- Performed a two-sample t-test assuming unequal variances
- Calculated test statistics, degrees of freedom, and p-values
- Compared statistical results between two datasets
- Interpreted the hypothesis-testing results
- Used Excel formulas to automate calculations and improve consistency

#### Skills Demonstrated

Microsoft Excel • Statistical Analysis • Data Analysis • Hypothesis Testing • T-Test • Confidence Intervals • Descriptive Statistics • Data Interpretation • Excel Formulas • Quantitative Reasoning
